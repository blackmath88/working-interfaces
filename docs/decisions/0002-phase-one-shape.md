# ADR 0001 — Keep phase one small

**Status:** Accepted for experiment  
**Date:** 2026-07-31

## Decision

Phase one contains one Astro field-manual app, raw HTML experiments, canonical knowledge files, and minimal validation.

React, Lit, database selection, API services, and MCP are deferred until a real consumer or workflow creates the need.

## Reason

The project must preserve the speed of one-shot HTML prototyping while testing the knowledge-first premise with the smallest possible implementation.
