# Demo portfolio navigation scenarios

All customer names and data are fictional. Unfinished station content is
explicitly labelled as prototype content.

1. Open Control Center and verify four customers and twelve use cases.
2. Expand and collapse each customer inline in the left navigation.
3. Switch from Sonnenhof to Alpinia and verify the customer overview.
4. Switch use cases with the overview selector and then use browser Back.
5. Open customer shared context; close it with the button and verify focus.
6. Open Helvetic Field Services → Servicebericht-Assistent (Phase 1).
7. Open Sonnenhof → Entlassungsbericht vorbereiten (Phase 2).
8. Open Helvetic Field Services → Störungstriage (Phase 3).
9. Inspect the blocked Evidence station in Richtlinien-Assistent.
10. Inspect the skipped Evidence reason in Forschungsvertrags-Triage.
11. Inspect the reopened Data Readiness reason in Ersatzteilvorschlag.
12. Navigate from a use-case journey to a station and use “Journey overview”.
13. Navigate from a station to its artifact and use the station parent link.
14. Verify long Nordstadt customer/use-case names truncate but retain tooltips.
15. At 390 px width, use drawer navigation and the full-width context sheet.
16. Select `Demo-Daten laden`; cancel once, then confirm explicit replacement.
17. Use `Restore previous data` after replacement and confirm the restore dialog.
18. Use browser Back/Forward across customer, journey, station, and panel URLs.
19. Open provenance and revision-history panels from an artifact.
20. Enter a malformed customer, station, or artifact ID and verify safe recovery.
