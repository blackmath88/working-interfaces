# Raw HTML experiments

This directory is the fast lane for visual and interaction prototypes.

Plain HTML, CSS, and JavaScript are welcome. TypeScript, automated tests, and
reusable component APIs are not required here. An experiment may remain visual
evidence without ever entering the published product or a production codebase.

When an experiment proves useful, document what it established. Promising parts
can later be migrated selectively or extracted into a shared structure. There
is no expectation that the whole experiment must be formalized.

Duplicate `_prototype-template.html` to start a new standalone experiment.
