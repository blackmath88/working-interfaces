# HTML experiments

This directory is a permanent, first-class lane for visual and interaction prototypes.

Plain HTML, CSS, and JavaScript are welcome. TypeScript, automated tests, and
reusable component APIs are not required here. An experiment may remain durable
design evidence without entering the published product or a production codebase.

When an experiment proves useful, document what it established. Promising parts
can later be formalized selectively or extracted into a shared structure. There
is no expectation that the whole experiment must be formalized.

Duplicate `_prototype-template.html` to start a new standalone experiment.
